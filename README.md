# GPG Editor

A simple text editor for symmetrically PGP/GPG encrypted files. Will cache the (one & only) key in secure storage between sessions.

## Install

```
$ flutter pub get
$ flutter build apk
$ adb install -r build/app/outputs/flutter-apk/app-release.apk
```
